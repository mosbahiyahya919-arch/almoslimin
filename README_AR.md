# تطبيق المسلمين — دليل البناء من الهاتف

هذا مشروع أندرويد أولي. ليس ملف APK جاهزًا للتثبيت. يمكن بناء APK تجريبي عبر خدمة GitHub Actions دون كمبيوتر، باستخدام متصفح الهاتف.

## بناء APK من الهاتف عبر GitHub

1. نزّل وفك ضغط `almoslimin_android_project.zip` في هاتفك باستخدام مدير الملفات.
2. افتح https://github.com وسجّل الدخول أو أنشئ حسابًا.
3. أنشئ مستودعًا جديدًا باسم `almoslimin` واجعله **Private** إذا رغبت، ثم أنشئه.
4. داخل المستودع اضغط **Add file → Upload files**.
5. ارفع **محتويات المجلد `almoslimin` بعد فك الضغط**، وليس ملف ZIP وحده. تأكد من رفع المجلد المخفي `.github/workflows` أيضًا. إن لم يظهر `.github` في مدير الملفات، فعّل إظهار الملفات المخفية.
6. اضغط **Commit changes** وانتظر حتى ينتهي الرفع.
7. افتح تبويب **Actions** في المستودع. يجب أن يبدأ سير العمل `Build APK` تلقائيًا. إذا لم يبدأ، افتح `Build APK` واضغط **Run workflow**.
8. انتظر حتى تظهر علامة النجاح الخضراء. افتح عملية البناء الناجحة، وانزل إلى **Artifacts**، ثم اضغط `almoslimin-debug-apk` لتنزيل ملف ZIP يحتوي على APK.
9. فك ضغط ملف الأثر الذي نزّلته، ثم اضغط `app-debug.apk` للتثبيت. قد يطلب أندرويد السماح للمتصفح أو مدير الملفات بتثبيت تطبيقات من هذا المصدر؛ لا تسمح بذلك إلا لأنك طلبت هذا البناء وتثق بالمصدر.

## مهم
- هذا APK تجريبي موقّع بمفتاح debug، وليس إصدارًا جاهزًا للنشر في Google Play.
- للنشر في Google Play، نحتاج لاحقًا إلى إنشاء إصدار Release موقّع، واختبار التطبيق، وإعداد سياسة الخصوصية وبيانات المتجر.
- لا تضع كلمات المرور أو مفاتيح التوقيع في المستودع.
- يجب التحقق من كل محتوى ديني ومواقيت الصلاة قبل اعتماد التطبيق. بعض الميزات المقترحة ما زالت غير منفذة.
